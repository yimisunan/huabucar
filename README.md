# 猫画布

本地运行的图片与视频生成画布。使用浏览器整理提示词、参考图、生成参数和返图，Python 后端负责同源代理、任务队列与结果保存。

## 启动

需要 Python 3。主服务使用标准库，无需安装依赖；部分缩略图功能可选安装 Pillow。

```bash
python3 生图服务器.py
```

浏览器打开 `http://127.0.0.1:8899/图片生成画布版.html`，在设置中选择供应商并填写自己的 API Key。项目不附带任何账户密钥或历史任务。

首次运行会自动创建 `.生图任务/`。API 配置、画布和本地收藏由浏览器保存；保留同一浏览器及访问地址可以继续使用原浏览器数据。

## 功能

- 文生图、参考图生成、局部修改和视频生成。
- 画布工程导入与导出、返图预览、参数复用与图片元数据。
- 提示词模板浏览、分类、搜索和收藏。
- 持久化任务队列、取消与恢复、异步任务查询和返图补取。
- 按供应商能力设置比例、分辨率、质量、格式与规划复杂度。
- 支持 OpenAI 兼容与原生任务协议；FutureAI 参考图先上传再提交 URL。

默认仅监听本机。需要局域网使用时设置 `HOST_ANY=1`，并按需配置代理令牌与上游主机白名单。

## 配置

| 环境变量 | 作用 | 默认值 |
| --- | --- | --- |
| `PORT` | 服务端口 | `8899` |
| `AUTO_OPEN` | 启动后自动打开浏览器，设为 `0` 可关闭 | `1` |
| `TASK_DATA_ROOT` | 私有任务、参考图与结果保存目录 | 项目内 `.生图任务/` |
| `TASK_MAX_CONCURRENT` | 本地任务逻辑并发 | `3` |
| `HOST_ANY` | 设为 `1` 允许局域网访问 | `0` |
| `PROXY_TOKEN` | 同源代理访问令牌 | 空 |
| `PROXY_ALLOW_HOSTS` | 可转发的上游主机，逗号分隔 | 空 |
| `ALLOW_PRIVATE` | 设为 `1` 允许代理访问内网 API | `0` |

`TASK_MAX_CONCURRENT` 是本地调度配置，不代表供应商账户额度。修改服务器代码后需要重启，前端更新后刷新页面即可。

## 目录

| 路径 | 用途 |
| --- | --- |
| `生图服务器.py` | Python 服务入口 |
| `server/` | HTTP、任务调度、供应商与数据处理模块 |
| `图片生成画布版.html` | 主画布页面 |
| `js/`、`css/` | 前端模块与样式 |
| `页面/` | 提示词与参考图库选择页面 |
| `图片生成供应商能力.json` | 供应商能力预设 |
| `提示词仓库/` | 随项目提供的提示词与角色模板 |
| `data/gallery/` | 参考图库索引，不含生成历史 |
| `更新参考图库索引.py` | 更新图库索引的独立工具 |
| `fonts/`、`icons/` | 本地字体与图标 |
| `安卓启动器/` | 可选 Android/Termux 启动器源文件，见其中使用说明 |

签名密钥、APK、任务数据、导出画布、维修记录、备份与缓存不进入 Git。图库索引更新工具可能访问外部站点，正常启动服务不需要先运行该工具。

## 数据与初始化

前端数据与后端任务数据分别保存。清理服务器任务目录不会清空浏览器画布；变更浏览器或访问地址可能导致原浏览器数据不可见。

需要重新初始化时先停止服务，并确认没有运行/排队任务；将 `.生图任务/` 整体移出项目留存，再启动即可生成新的空任务库。需要旧返图时可在停服后放回原目录，避免覆盖新任务。

干净检出不包含任何本机历史运行数据、签名或个人配置。历史数据的备份由使用者单独保管。

## 调度维护约定

超生成保持现有失败补位、审核返还与达标取消逻辑；返还上限为 `attempts`，达标后取消尚未开始任务，已开始任务继续收尾并保留返图。未知提交状态优先查询原任务，未确认幂等时不要自动重发上游生成请求。

规划复杂度使用 `complexity`（`low`、`medium`、`high`），与 `quality` 分开；未指定则省略。GIF 按供应商真实返图格式保存完整帧。供应商能力及现有提示词、参考图与任务数据修改约定见 `AGENTS.md`。
