【最终任务】
生成一张高端、精致、统一、可信的非写实 2.5 次元游戏角色最终主视觉。人物不是摆姿势，而是在真实完成一项日常任务，摄影机恰好捕捉动作进行中的自然瞬间。整体为韩式商业级伪厚涂、非写实 2.5 次元、精致数字人物、低饱和高级游戏最终视觉。视觉优先级：角色身份与面部辨识度 > 动作 > 服装 > 环境与氛围。

【人物变量】
延续 IMAGE 1、IMAGE 2 的年龄：28 岁成年女性。
人物身份：现代中国女性 / [集团董事长]。
核心气质：淑女、成熟、妩媚、生活化。
身材：高挑、自然、可信的动漫成年女性人体，[沙漏型身材]，[身高约 190 cm]。
胸臀：丰满 C 杯，体积自然，与肩宽、胸廓、腰部、骨盆、大腿比例协调，符合自然重力与支撑关系。
头发基调：黑色、自然光泽。
当前生活任务：[集团总裁办公室下班前的办公室。她刚敲完一大段文字，揉了揉肩颈，身体缩进椅子里，腿也不自觉蜷起来。瞬间： 她正在活动肩膀，突然听见你喊她，她保持这个姿势，转过头看镜头。]。
主要操作对象：[当前使用的工具或物体]。
当前注意力对象：[此刻正在观察或处理的对象]。
当前动作中间态：[动作做到一半，而不是动作开始前或完成后的静止状态]。

【1. 角色身份锁定】
人物必须具有明确身份辨识度，而非泛化的“漂亮东方女性”。她是成熟、妩媚、淑女、生活化的成年女性，不是模特，也不是商业写真对象，而是在自己的生活空间中完成真实任务的人。“集团董事长”等身份只通过生活环境、行为选择、服装氛围、表情与气质体现，不得重新设计人物面部。

【2. 核心行为逻辑】
人物必须处于明确的日常行为过程中，而非摆姿势。画面应能回答：她正在做什么、为什么这样做、身体为何形成当前姿势。动作必须形成完整因果链：任务目标 → 手部操作 → 手与物体接触 → 肩、肘、腕受力 → 躯干调整 → 骨盆转向 → 重心转移 → 双腿承重差异 → 衣物拉伸/折叠/垂坠 → 发丝与饰物轻微动态 → 环境合理反馈。必须是动作进行中的中间帧，有明确“前一秒”和“下一秒”，而非准备、展示或完成状态。不要为构图强改动作，也不要为展示脸、服装或身材重新组织肢体。

【3. 生活感】
人物必须像真实生活在该空间中，而不是“角色站在厨房背景里”。至少一个环境对象必须真正参与动作，例如手与工具、容器、食物、家具、门、抽屉、衣物、植物或书籍发生真实接触。道具不能只是装饰，必须被握住、推动、打开、移动、整理、擦拭、搅拌、拿取或放置。可加入少量自然生活痕迹，如已使用物品、处理中食材、轻微移动物件和自然摆放用品，但不要堆砌杂物；生活感来自真实行为与关系，而非杂乱背景。

【4. 动作中间态】
动作必须让观者自然推测刚才发生了什么、下一秒会发生什么。允许轻微不对称、自然遮挡、动作残留和非展示性姿态。避免双手整齐摆放、双腿刻意并拢、肩胯刻意打开、身体正对镜头、双脚对称、手部刻意展示、动作停顿。人物是在执行任务，而不是等待摄影师拍照。

【5. GAZE + HEAD ORIENTATION / 视线与头部方向】
注意力优先服从当前任务，同时保持 IMAGE 1 的面部辨识度。默认：身体朝向操作对象，肩膀、躯干、骨盆与动作方向一致；头部轻微朝向摄影机，眼睛看向任务对象。优先轻微三分之四、自然回头、轻微侧脸、轻微低头但仍清晰可辨。眼睛可看向手中工具、桌面物体、食材、家具等任务对象，不要求直视镜头，但不要让脸完全背离摄影机。核心原则：“眼睛看向任务，脸部仍保持角色身份可见。”

禁止完全背脸、极端侧脸、纯侧面、头部完全转离摄影机、头发大面积遮脸、过度低头导致眼鼻嘴关系消失。若动作参考与面部身份冲突，优先保持 IMAGE 1 面部身份，只适度调整头部角度。

【6. IMAGE 1 — PRIMARY FACIAL IDENTITY MASTER】
IMAGE 1 是人物面部身份唯一最高优先级参考。最终必须始终是 IMAGE 1 的同一张脸，无论身体朝向、动作、服装、环境、光线或镜头角度如何变化，都不得重新设计面部。严格保持：脸型与骨架、宽高关系、面部宽度与体积、眼睛形态与眼裂、双眼皮、眼距、眉眼关系、鼻梁/鼻尖/鼻翼、鼻唇关系、上下唇比例、嘴唇轮廓、嘴角、下巴、下颌线、脸颊体积、软组织体积、年龄感、皮肤基准与整体辨识度。

将 IMAGE 1 理解为“固定面部身份模板”，而非单纯正面参考。人物转身、低头、侧身或看向其他对象时，只改变头部朝向、视线与可见角度，不重新生成脸。即使为三分之四、轻微侧脸、低头或身体偏转，仍必须保持眼距、鼻梁走向、鼻尖、嘴唇、下颌线、脸型宽度与脸颊体积等核心特征。优先正面、轻微三分之四、自然三分之四等可清晰验证身份的角度；避免极端纯侧脸、完全背脸、脸部严重被头发遮挡和大幅度低头。原则：改变人物正在看哪里，不改变人物是谁。

【7. IMAGE 2 — HAIR / CHARACTER CONTINUITY】
IMAGE 2 只负责发型结构、长度、发量、刘海、脸周碎发、编发/扎发结构、发饰、耳饰及角色整体外观连续性，并辅助理解正面、三分之四和侧面视角下的头发关系；不得重构 IMAGE 1 的面部身份。头发保持自然层次、清晰发束、适量细发丝、柔和高光与轻微动态，可随动作产生自然摆动和碎发变化，但不得无依据改成完全不同的发型。

【8. IMAGE 3 — ACTION / POSE / BODY MECHANICS REFERENCE】
IMAGE 3 负责动作、动作方向与中间状态、身体朝向、头身关系、躯干方向与扭转、骨盆方向、肩胯关系、手臂轨迹、肘腕角度、手部位置、手与物体空间关系、双腿位置、膝盖弯曲、大腿/小腿前后关系、双脚、支撑关系、重心、遮挡、动作节奏、观察方向及人物与环境的空间关系。

必须尽可能忠实重建 IMAGE 3 的核心动作与空间关系，重点理解“人物正在执行这一动作时，为什么身体形成这样的空间关系”，而不是复制静态轮廓。禁止镜像、拉直、对称化、替换成相似 Pose，也禁止为了展示身体或服装改变核心动作。IMAGE 3 不负责人物身份、面部、发型、肤色、服装和画风。

【9. IMAGE 4 — CLOTHING REFERENCE ONLY】
IMAGE 4 只负责服装类别、轮廓、版型、比例、长度、领口、肩部、袖型/袖长、腰部结构、下摆、衣片关系、层叠、缝线、蕾丝、边缘、纹样、图案、面料、厚薄、褶皱、垂坠与受力方式。

服装必须根据当前角色身体、IMAGE 3 的动作、重心和空间关系重新计算受力，运动中自然产生拉伸、压缩、堆叠、滑动、悬垂、重力折痕与局部遮挡。禁止继承 IMAGE 4 模特的人体比例、脸、发型、肤色、动作和人物身份；禁止额外添加 IMAGE 4 不存在的服装、花纹、蕾丝、蝴蝶结、首饰、外套等设计元素。

【10. 身体结构】
保持可信的成年女性人体结构与动漫人物体积。肩颈、锁骨、肩关节、胸廓、腰部、骨盆、髋关节、大腿、膝盖、小腿、脚踝、足部必须符合正常解剖关系。保持自然肩颈/腰胯比例、可信身体重量、合理重心、四肢长度、手掌与手指比例、关节结构及稳定的肩宽、胸廓、腰、骨盆、大腿、小腿关系。身体必须属于当前角色，不得被 IMAGE 3 或 IMAGE 4 的参考人物比例带偏。

禁止纸片人、极端超模比例、异常长腿、异常细腰、过度拉长身体、错误骨盆/肩胯/躯干、关节扭曲、漂浮肢体、重复肢体、错误重心和不可能的人体扭转。手部正常五指、掌骨和指关节合理，并与物体形成可信接触；脚部拥有合理脚踝、脚掌、脚趾数量与真实地面接触。

【11. 皮肤、面部材质与肤色锁定】
人物皮肤是整张图的主要色彩锚点，也是身份的重要组成部分。严格保持参考人物既定肤色：粉白至冷白、清透、柔和、自然红润。稳定保持色相、明度和适度色度，不因墙面、床品、家具、窗外景色、灯光或空间氛围而明显漂移。阴影只允许降低亮度，不得把皮肤变成灰、青灰、蓝灰、黄、橙、棕或无血色惨白。

保持细腻、清透、柔和的体积感与轻微次表面散射，避免塑料、蜡像、橡胶、过度磨皮和油腻反光。环境允许有冷暖变化，但不得大面积染入人物皮肤，只允许极轻微、受控反射。原则：人物肤色优先于环境氛围。

【12. 妆容】
精致但克制，只强化 IMAGE 1 原有面部结构和身份。可有自然眉形、柔和眼妆、淡唇色、自然腮红与轻微高光。禁止欧美浓妆、网红妆、舞台妆、重烟熏、厚重鼻影、夸张鼻梁高光、浓烈唇色，以及通过修容改变面部骨架。

【13. 背景与环境】
采用现代、高级、安静、非写实现代室内生活空间。背景可用浅灰、米灰、灰白、冷中性色或轻微低饱和色，但只服务人物，不得成为覆盖整图的统一滤镜。背景可低对比、低细节、低锐度，但这些限制只作用于背景，不作用于人物皮肤、脸部、头发、手部和服装主体。

环境应干净、柔和、有空气感，但禁止灰雾、青灰污染、整体发蒙、曝光过低、人物与背景融成同一灰度。墙壁、床品、窗帘、家具等可偏冷，但不得把青灰、蓝灰、黄灰或橙灰明显反射到人物皮肤。必须保持人物与环境自然的色彩分离。

【14. 环境反馈】
人物动作必须对环境产生合理反馈：握物体有接触，移动物体有空间变化，搅拌时容器内产生轻微运动，开柜门时手臂与门形成明确空间关系，浇花时水流与植物建立关系，整理衣物时衣物产生堆叠/移动，坐下时椅子承重，弯腰时身体与家具保持合理距离。所有物体遵守重力、空间、遮挡、尺寸和接触逻辑。

【15. LIGHTING + COLOR：人物肤色优先】
采用高级、柔和、清澈、自然的日间室内光线。氛围可偏冷或中性，但面部与裸露皮肤必须保持干净、明亮、稳定的原始肤色。

视觉层级：
第一层：人物皮肤与面部——全图白平衡和色彩基准。
第二层：服装与头发——配合肤色塑造材质和轮廓。
第三层：环境与背景——围绕人物协调。

Key light：干净、中性或轻微暖中性的柔和主光，优先保证脸部、眼睛、鼻梁、嘴唇、下颌和裸露皮肤清晰健康。
Fill light：控制阴影密度，不压成灰黑，并保留粉白、冷白或自然肤色色彩信息。
Rim / edge light：极克制，只用于人物与背景分离，不得以蓝、青、紫、橙色污染皮肤。
环境光可以变化，但人物肤色不能随环境漂移。

背景偏冷时，人物仍保持粉白、冷白、自然红润；背景偏暖时，人物仍保持冷白至粉白基准；环境较暗时可压暗背景，但人物脸部与皮肤仍需保持明度和色彩层次；环境较亮时，不得导致人物脸部过曝。

禁止统一冷灰、蓝灰、黄灰、棕灰滤镜、强烈去饱和，以及把“低饱和”变成“低明度、低对比、低肤色色度”。整体应为：低饱和环境 + 清透人物肤色 + 明确主体层级 + 柔和完整的明暗关系。人物可比背景拥有更高面部明度、更清晰局部对比度、更稳定肤色色度与更丰富材质，但不要生硬打光或广告式高光。

【16. CAMERA + COMPOSITION】
9:16 竖版，全身完整入镜：头顶、完整头发、双手、躯干、双腿、双脚、鞋履均不可裁切。人物位于核心区域并保持足够视觉尺度，使脸部、眼神、比例、动作与服装清晰可辨，同时保留适量背景空间证明生活环境。

摄影机像记录生活的观察者，而不是指导模特摆 Pose。允许轻微偏心构图、自然不对称、合理前景/家具局部遮挡与动作造成的遮挡。禁止超广角、鱼眼、严重透视、夸张近大远小、极端低机位、高机位，以及为了性感设计的极端角度。构图必须服务动作，不得重写动作。

【17. CANDID CAPTURE】
最终画面必须拥有高级游戏最终图的完成度，但人物行为应像真实生活中的自然瞬间。摄影机只是记录者，人物不需要意识到镜头存在。禁止正对镜头摆 Pose、模特式站立、刻意展示身材、收腹、挺胸、抬臀、打开肩胯、安排双腿或停下来展示服装。“最终级”来自人物塑造、构图、灯光、材质、色彩、细节和环境设计，而不是摆拍感、性感展示感或摄影棚写真感。

【18. ART DIRECTION】
整体为韩式商业级伪厚涂、非写实 2.5 次元、高级游戏角色最终主视觉、精致数字人物、低饱和高级色彩。低饱和主要用于环境、背景和次要元素，不对整图统一去饱和。人物必须保持清透粉白肤色、自然红润、稳定肤色、柔和皮肤层次、清晰眼睛、细腻面部材质、柔和头发高光、明确服装材质与自然体积。

最终视觉：高级低饱和环境 + 清透人物肤色 + 柔和高质感人物光照。不要将“低饱和高级”理解为灰蒙、暗沉、无血色、低明度或整体去色。

【19. 视觉层级】
严格优先级：

1. FACE / IDENTITY / SKIN TONE
2. ACTION / BODY MECHANICS
3. CHARACTER SILHOUETTE / CLOTHING
4. ENVIRONMENT / ATMOSPHERE

人物脸部身份、皮肤色相、皮肤明度和眼神优先于环境氛围。环境可降低亮度、饱和度、细节密度与对比度，但不得同步作用于人物。宁可降低背景存在感，也不要牺牲人物粉白肤色、面部明度、眼睛清晰度和皮肤层次。人物是色彩与视觉中心，环境是氛围陪衬。

【20. HARD CONFLICT RULES】
FACE / IDENTITY → IMAGE 1
HAIR / CHARACTER CONTINUITY → IMAGE 2
ACTION / POSE / BODY MECHANICS → IMAGE 3
CLOTHING / TEXTILE / GARMENT DESIGN → IMAGE 4
ART STYLE / RENDERING → 本提示固定视觉风格
CHARACTER MOOD / PERSONALITY → 当前人物变量与本提示设定

禁止平均融合不同人物、平均融合不同脸、重新设计 IMAGE 1 的脸、让 IMAGE 2 覆盖 IMAGE 1 面部、让 IMAGE 3 改变人物身份或身体比例、让 IMAGE 4 改变人体比例、让服装决定人体比例、让灯光改变肤色、让背景竞争人物主体、让动作为了构图而改变。

冲突优先级：
SKIN TONE > ENVIRONMENT COLOR
FACE CLARITY > ATMOSPHERIC MOOD
PRESERVE SKIN TONE; COOL THE BACKGROUND INSTEAD

当环境需要更暗、更冷、更低饱和时，优先调整背景和环境表面的亮度、饱和度、色温，而不是人物肤色。环境不得把人物皮肤染成灰、蓝灰、黄、橙、棕或其他环境色。例如：灰墙不得变成灰色皮肤，蓝色窗光不得变成蓝灰皮肤，暖灯不得变成黄色皮肤，棕色家具反射不得变成棕色皮肤，冷色环境不得让整个人物发灰，低饱和背景不得让人物失去肤色色度。人物皮肤始终是全图稳定色彩基准。
