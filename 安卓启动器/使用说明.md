# 猫画布 Android/Termux 启动器

此目录保存可选启动器的源文件。主项目可以直接用 Python 启动，不需要先安装或构建 APK。

启动器只负责唤醒 Termux、运行本地服务器并打开默认浏览器，不包含 Python、网页副本或 WebView。

## 使用条件

- Android 8.0 及以上版本，已安装 Termux 与 Python。
- Termux 已授予共享存储权限，并允许外部应用通过 `RUN_COMMAND` 执行命令。
- APK 需要获得 `com.termux.permission.RUN_COMMAND` 权限。
- 项目中的路径需要与实际部署位置一致。`start.sh`、`launch.py` 和 `src/local/catcanvas/launcher/MainActivity.java` 保留现有部署约定，换机或更改目录时应同步调整。

默认服务地址为 `http://127.0.0.1:8899/图片生成画布版.html`。保留原浏览器和地址，可以继续使用该来源下原有的画布与配置。

## 源文件

| 文件 | 用途 |
| --- | --- |
| `MainActivity.java` | Android 启动界面、Termux 调用和就绪检查 |
| `launch.py` | 服务检查、启动互斥与运行日志 |
| `start.sh` | Termux 启动入口 |
| `AndroidManifest.xml`、`res/` | Android 清单和资源 |
| `build.py` | 本地 APK 构建入口 |

服务已运行时会复用现有实例；启动失败会显示提示，不会自动杀掉占用端口的其他进程。

## 构建

需要 JDK、Android 平台 JAR、R8/D8、`aapt`、`zipalign`、`apksigner` 和 `keytool`。设置适合本机的工具路径后，从项目根目录运行：

```bash
python3 安卓启动器/build.py
```

可配置 `CATCANVAS_ANDROID_JAR`、`CATCANVAS_RESOURCES_JAR`、`CATCANVAS_R8_JAR`，以及 `CATCANVAS_AAPT`、`CATCANVAS_JAVAC`、`CATCANVAS_JAVA`、`CATCANVAS_ZIPALIGN`、`CATCANVAS_APKSIGNER`、`CATCANVAS_KEYTOOL`。

构建输出写入 `build/` 和 `猫画布启动器.apk`，均不进入 Git。构建脚本会在缺少密钥时创建本地开发签名；覆盖升级原有安装必须先恢复原密钥到 `.signing/catcanvas.keystore`，否则新 APK 的签名会不同。

仓库不包含原签名与 APK。覆盖升级前必须确认原签名密钥可用；原密钥不可用时不要把新签名 APK 当作原版升级包。换机使用者应自行创建和保管签名，不能用源码恢复原密钥。

## 运行与更新

修改服务器代码后需要停止旧服务再启动，通常无需重新打包 APK。修改部署路径、启动协议或 APK 页面时才需要更新启动器。

启动器不保证绕过厂商后台冻结。长时间任务可让 Termux 保持可见；关闭浏览器不会主动停止服务。停止服务器时，在对应 Termux 会话按 Ctrl+C。
